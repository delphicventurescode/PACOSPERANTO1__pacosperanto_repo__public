# Welcome Aboard, Anand!

Now that the Squad of Avengers is officially well on the way to being assembled, it’s officially time to talk about our very first assignment.

Think of this like a university course, except without the existential dread: the only required deliverable is a short 7-to-10-minute talk in MP4 format. Every single homework task and/or reading along the way is completely optional. We’re pivoting from how we ran the Fulmo Talk Series—this time, the strategy is strictly zero stress and maximum fun, with a few quirky mini-projects sprinkled in to keep things entertaining.

---

## Assignment #1

* **Pick Your Victims:** Grab any 4 to 6 photos from your personal vault. *(Yes, even the ancient, slightly embarrassing ones from the bottom of your Facebook profile count.)*
* **Time Travel:** Slap an aggressive 1980s retro filter on them. ChatGPT has all the details. If you open ChatGPT right this moment, it will probably have a clickable photo which has that 80's look to it.
* **Add the Esperanto Touch:** Give each vintage masterpiece a caption written in Esperanto.
* **Post to GitHub:** Create a GitHub account, if you don't have one; create a public GitHub repo, and post your photos to your own GitHub.
