# Nursery Rhymes in the ConLang.

It is very easy to construct nursery rhymes in Pacosperanto.

### Example #1

Frato Jako,

Frato Jako,

Levu vin,

Levu vin,

Jen la ghaNTAo,

Jen la ghaNTAo

Bim bam bom,

Bim bam, bom.

### Example #2

Brilu, brilu, eta taar'
Brilu, brilu, eta taar',
Diamanto sur ĉiel'!
Diru, kio estas vi,
Tiel alta super ni?
Brilu, brilu, eta taara',
Diamanto sur ĉiel'!
